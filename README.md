# Ночной гость

3D-хоррор-стелс для iOS/Android (Vite + vanilla JS + three.js + Capacitor).

- Веб-тест: https://screpka228.github.io/night-guest/
- Debug APK: Releases → `latest-debug` (https://github.com/screpka228/night-guest/releases/tag/latest-debug)

## Разработка

```
npm install
npm run dev
```
